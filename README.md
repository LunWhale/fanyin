# 梵音 · 从零开始读梵语

在线学习：**https://lunwhale.github.io/fanyin/**

给中文母语者的罗马体梵语自学网站：12 单元、60 课、12 次单元测验，562 个词，1,378 条本地预生成的慢速梵语音频。只用 26 个拉丁字母与 IAST 变音符号，不教天城体。

- 每课先学音、再学词、后练习；词卡默认藏起中文。
- 学完可读《薄伽梵歌》选段、《心经》、《中论》偈颂与《五卷书》改写故事。
- 支持间隔复习、听写、词典（含 20,658 条梵汉大辞典检索）、发音总表与毕业证书。

本仓库只包含构建后的静态站点；课程源文件、校验器与音频生成脚本保留在本地工程中。
